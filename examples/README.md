# Zlang examples

Every example is a self-contained golden fixture. Each directory contains:

- `main.zlang` — the Zlang program.
- `main.c` — the C generated by `zlang-compile`, committed as a golden artifact.
- `expected.txt` — the exact stdout produced by the native binary.
- `README.md` — a short explanation of the program and the language features it exercises.

CTest compiles each example, compares the generated C byte-for-byte against `main.c`, runs the
binary and compares stdout against `expected.txt`.

```sh
ctest --test-dir build --output-on-failure -L module:examples
ctest --test-dir build --output-on-failure -L category:algorithms
ctest --test-dir build --output-on-failure -L category:features
ctest --test-dir build --output-on-failure -R zlang.examples.features.arrays_nd
```

## Categories

### Algorithms

Compact programs that solve a recognizable problem. They are useful for reading control flow,
arrays and functions together.

| Example | Exercises |
| --- | --- |
| [bubble_sort](algorithms/bubble_sort/README.md) | nested `for`, checked indexed writes, `foreach` |
| [collatz](algorithms/collatz/README.md) | `while`, modulo, conditional arithmetic |
| [factorial](algorithms/factorial/README.md) | `for`, compound assignment |
| [fibonacci](algorithms/fibonacci/README.md) | fixed arrays, indexed reads and writes |
| [fizzbuzz](algorithms/fizzbuzz/README.md) | `else if` chains, modulo, scalar printing |
| [gcd](algorithms/gcd/README.md) | functions, `clone` parameters, `while`, `return` |
| [matrix_multiply](algorithms/matrix_multiply/README.md) | 2D arrays, nested loops, multidimensional `foreach` |
| [pi](algorithms/pi/README.md) | integer-only approximation, boolean toggle |
| [sieve](algorithms/sieve/README.md) | boolean arrays, nested loops, prime marking |
| [sum_of_squares](algorithms/sum_of_squares/README.md) | `foreach`, checked arithmetic |

## Regenerating a golden

After an intentional emitter change, regenerate the affected fixture and review the diff:

```sh
cd examples/features/arrays_nd
../../../build/tools/zlang-compile/zlang-compile main.zlang
./main > expected.txt
```

Then run the example test. Never update `main.c` by hand.
