# Zlang examples

Every example is a self-contained golden fixture. Each directory contains:

- `main.z` — the Zlang program, always with an explicit `main` function.
- `main.c` — the C generated by `zc`, committed as a golden artifact.
- `expected.txt` — the exact stdout produced by the native binary.
- `README.md` — a short explanation of the program and the language features it exercises.

CTest compiles each example, compares the generated C byte-for-byte against `main.c`, runs the
binary and compares stdout against `expected.txt`.

```sh
ctest --test-dir build --output-on-failure -L module:examples
ctest --test-dir build --output-on-failure -L category:algorithms
ctest --test-dir build --output-on-failure -L category:features
ctest --test-dir build --output-on-failure -R zlang.examples.features.arrays_nd
```

## Categories

### Algorithms

Compact programs that solve a recognizable problem. They are useful for reading control flow,
arrays and functions together.

| Example | Exercises |
| --- | --- |
| [bubble_sort](algorithms/bubble_sort/) | nested `for`, checked indexed writes, `foreach` |
| [collatz](algorithms/collatz/) | `while`, modulo, conditional arithmetic |
| [factorial](algorithms/factorial/) | `for`, compound assignment |
| [fibonacci](algorithms/fibonacci/) | fixed arrays, indexed reads and writes |
| [fizzbuzz](algorithms/fizzbuzz/) | `else if` chains, modulo, scalar printing |
| [gcd](algorithms/gcd/) | functions, `clone` parameters, `while`, `return` |
| [matrix_multiply](algorithms/matrix_multiply/) | 2D arrays, nested loops, multidimensional `foreach` |
| [pi](algorithms/pi/) | int32-only approximation, boolean toggle |
| [sieve](algorithms/sieve/) | boolean arrays, nested loops, prime marking |
| [sum_of_squares](algorithms/sum_of_squares/) | `foreach`, checked arithmetic |

## Regenerating a golden

After an intentional emitter change, regenerate the affected fixture and review the diff:

```sh
cd examples/features/arrays_nd
../../../build/tools/zc/zc main.z
./main > expected.txt
```

Then run the example test. Never update `main.c` by hand.
