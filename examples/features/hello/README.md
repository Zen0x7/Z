# Hello from Zlang

The smallest executable example: prints a string and a newline.

This example exercises:

- string literals;
- `print` calls;
- newline escapes;
- the generated `_zlang_literal_0` declaration.

It is the recommended starting point for reading the golden C layout.

```sh
ctest --test-dir build --output-on-failure -R zlang.examples.features.hello
```
